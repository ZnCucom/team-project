# Lo-Fi Companion

[English](README.md) | [中文](README.zh-CN.md)

## 项目简介

Lo-Fi Companion 是一个使用 Java Swing 开发的桌面学习陪伴应用，目标是在学习或工作时提供一个轻松、舒适并具有陪伴感的环境。

应用将包含几个彼此关联的主要功能：

- 专注与任务管理，
- 虚拟桌宠，
- 本地 WAV 背景音乐，
- 以及基于天气变化的场景。

项目的目标是创建一个小型虚拟学习空间，让用户能够规划需要完成的事情、专注学习、播放音乐，同时获得来自虚拟宠物的简单陪伴和反馈。

第一版计划支持一个用户、一只宠物、一个轻量级 To-Do List、一个专注计时器、少量宠物对话、本地 WAV 音乐播放功能、天气场景，以及一个主要的 Java Swing 应用窗口。

## 核心 User Stories

### 1. 专注计时器与 To-Do List
**负责人：[Member A]**

作为一名学生，我希望能够管理待办任务并使用专注计时器，从而安排需要完成的事情，并追踪自己的学习进度。

第一版计划包含：

- 可设置时长的专注计时器，
- 开始、暂停、继续和重置控制，
- 已完成专注 session 的记录，
- 以及一个用于管理学习任务的轻量级 To-Do List。

To-Do List 的具体设计将在后续进一步完善。第一版可能支持添加任务、将任务标记为已完成以及删除任务等基础操作。

完成一次专注 session 后，虚拟宠物还可以显示一句简短的鼓励。

---

### 2. 桌宠互动
**负责人：[Member B]**

作为一名用户，我希望能够给虚拟宠物起名、与它互动，并随着亲密度提升解锁新的对话，从而在学习时获得陪伴感。

第一版将允许用户：

- 给宠物起名，
- 与宠物进行简单互动，
- 提升 friendship progress，
- 根据 friendship progress 解锁不同的对话内容。

当用户完成一次专注 session 或完成一个任务时，宠物也可以做出简单回应。

---

### 3. 本地 WAV 音乐播放器
**负责人：[Member C]**

作为一名学生，我希望能够播放内置的放松音乐，并将自己的本地 WAV 文件添加到播放列表中，从而无需离开应用就能个性化自己的学习环境。

第一版将允许用户：

- 从少量内置的放松 WAV 音乐中选择曲目，
- 将兼容的本地 `.wav` 文件添加到播放列表，
- 播放、暂停、继续以及切换曲目，
- 在应用重新打开时恢复已导入曲目的文件路径，
- 在文件丢失或格式不受支持时看到清楚的错误提示。

播放功能将通过 interface 封装 Java 标准音频 API，使应用逻辑保持可测试，并避免依赖具体的音频实现。

导入的曲目仍保存在用户电脑上的原始位置。如果原文件被移动或删除，应用可能无法继续使用该曲目。

---

### 4. 天气场景
**负责人：[Member D]**

作为一名用户，我希望能够选择一个城市，并让房间场景根据该城市当前的天气变化，从而让学习环境与现实世界产生联系。

第一版将允许用户：

- 输入或选择城市，
- 通过外部天气 API 获取当前天气，
- 将天气映射为少量场景类型，例如晴天、多云、下雨或下雪，
- 显示对应的房间背景。

如果天气数据获取失败，应用将显示默认场景，同时保证其他功能仍然可以正常使用。

## 功能分工

每位组员主要负责应用中的一个完整功能区域，包括对应的界面、应用逻辑、Clean Architecture 组件以及相关测试。

| 组员 | 主要功能区域 | 主要职责 |
| --- | --- | --- |
| [Member A] | 专注与任务管理 | 专注计时器、专注 session 记录、To-Do List、相关 UI 和测试 |
| [Member B] | 桌宠互动 | 宠物状态、亲密度系统、对话系统、宠物 UI 和测试 |
| [Member C] | 本地 WAV 音乐播放器 | 内置与导入 WAV 曲目、歌单与播放控制、本地曲目持久化、相关 UI 和测试 |
| [Member D] | 天气场景 | 天气 API 接入、天气到场景的映射、天气 UI、错误处理和测试 |

共享的应用组件、功能整合以及整体设计决策将由整个团队共同讨论和 review。

## 功能之间的联动

这些功能应当组成一个完整应用，而不是四个彼此完全独立的小程序。

例如：

- 完成一次专注 session 后，可以提升宠物亲密度并触发一句鼓励对话，
- 完成一个 To-Do 任务后，也可以触发宠物的简单回应，
- 天气系统可以改变房间背景，
- 用户使用计时器或 To-Do List 时，本地音乐可以继续作为学习背景音乐。

第一版将保持这些联动简单，避免因为功能之间过度耦合而增加实现难度。

---

## 数据持久化

各项功能将使用适合自身数据的本地文件格式保存需要持久化的信息。

保存的数据可能包括：

- 宠物名称，
- friendship progress，
- 已完成的专注 session，
- To-Do List 数据，
- 已导入 WAV 文件的路径以及当前选择的曲目，
- 以及所选择的城市。

当用户重新打开应用时，这些信息将被恢复。

敏感的认证凭据或 secret 不会直接保存在项目仓库中。

---

## 计划使用的外部 API

### Weather API

天气功能将使用一个外部天气服务来获取指定城市的当前天气信息。

目前具体使用哪一个天气 API provider 尚未最终确定。

天气功能同样会通过 interface 与主要应用逻辑隔离，这样未来即使更换外部天气服务，也不需要对应用的核心逻辑进行大规模修改。

如果天气数据无法获取，应用将使用默认场景。

---

## 第一版范围

Lo-Fi Companion 的第一版计划包含：

- 一个 Java Swing 主窗口，
- 一只虚拟宠物，
- 一个简单的 friendship 系统，
- 基础宠物对话，
- 一个专注计时器，
- 专注 session 记录，
- 一个轻量级 To-Do List，
- 本地 WAV 歌单以及基础播放控制，
- 当前天气查询，
- 几种基于天气变化的房间场景，
- 以及本地数据持久化。

项目将优先保证应用规模较小但功能完整、可靠，而不是一开始加入大量复杂功能。

---

## 第一版暂不包含的功能

以下功能目前不计划加入第一版：

- 多人模式，
- Lo-Fi Companion 自身的用户账户系统，
- 云同步，
- 多只宠物，
- 复杂剧情分支，
- 高级任务管理功能，
- 在线音乐串流以及高级歌单管理，
- 高级桌面悬浮功能，
- AI 生成对话。

只有在核心功能完成后，团队才会考虑是否加入这些扩展功能。
