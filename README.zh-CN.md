# Lo-Fi Companion

[English](README.md) | [中文](README.zh-CN.md)

## 项目简介

Lo-Fi Companion 是一个使用 Java Swing 开发的桌面学习陪伴应用，目标是在学习或工作时提供一个轻松、舒适并具有陪伴感的环境。

应用将包含四个主要功能：

- 专注计时器，
- 虚拟桌宠，
- 背景音乐，
- 基于天气变化的场景。

项目的目标是创建一个小型虚拟学习空间，让用户能够专注于自己的学习或工作，同时获得来自虚拟宠物的简单陪伴和反馈。

第一版将支持一个用户、一只宠物、少量对话和音乐，并使用一个主要的 Swing 应用窗口。

---

## 核心 User Stories

### 1. 专注计时器
**负责人：[Member A]**

作为一名学生，我希望能够设置、开始、暂停、继续和重置专注计时器，并查看已完成的专注记录，从而更好地安排和追踪自己的学习时间。

第一版将允许用户：

- 选择专注时长，
- 开始、暂停、继续和重置计时器，
- 记录已完成的专注 session，
- 查看已经完成的 session 数量。

完成一次专注 session 后，虚拟宠物还可以显示一句简短的鼓励。

---

### 2. 桌宠互动
**负责人：[Member B]**

作为一名用户，我希望能够给虚拟宠物起名、与它互动，并随着亲密度提升解锁新的对话，从而在学习时获得陪伴感。

第一版将允许用户：

- 给宠物起名，
- 与宠物进行简单互动，
- 提升 friendship progress，
- 根据 friendship progress 解锁不同的对话内容。

当用户完成一次专注 session 时，宠物也可以做出简单回应。

---

### 3. 背景音乐
**负责人：[Member C]**

作为一名用户，我希望能够选择背景音乐、控制播放，并调节音量，从而为自己创造一个舒适的学习环境。

第一版将允许用户：

- 从少量内置音乐中选择曲目，
- 播放和暂停音乐，
- 切换不同曲目，
- 调节播放音量，
- 在应用重新打开时恢复上一次的音乐偏好。

---

### 4. 天气场景
**负责人：[Member D]**

作为一名用户，我希望能够选择一个城市，并让房间场景根据该城市当前的天气变化，从而让学习环境与现实世界产生联系。

第一版将允许用户：

- 输入或选择城市，
- 通过外部天气 API 获取当前天气，
- 将天气映射为少量场景类型，例如晴天、多云、下雨或下雪，
- 显示对应的房间背景。

如果天气数据获取失败，应用将显示默认场景，同时保证其他功能仍然可以正常使用。

## 功能分工

每位组员主要负责一个完整的 use case，包括该功能对应的界面、应用逻辑、Clean Architecture 组件以及测试。

| 组员 | 主要功能 | 主要职责 |
| --- | --- | --- |
| [Member A] | 专注计时器 | 计时逻辑、专注 session 记录、计时器 UI 和相关测试 |
| [Member B] | 桌宠互动 | 宠物状态、亲密度系统、对话系统、宠物 UI 和相关测试 |
| [Member C] | 背景音乐 | 曲目选择、播放控制、音量控制、音乐偏好和相关测试 |
| [Member D] | 天气场景 | 天气 API 接入、天气到场景的映射、天气 UI、错误处理和相关测试 |

共享的应用组件、功能整合以及整体设计决策将由整个团队共同讨论和 review。

---

## 数据持久化

应用将使用 JSON 在本地保存用户数据。

保存的数据可能包括：

- 宠物名称，
- friendship progress，
- 已完成的专注 session，
- 音乐偏好，
- 音量设置，
- 以及所选择的城市。

当用户重新打开应用时，这些信息将被恢复。

---

## 外部 API

天气功能将使用一个外部天气服务来获取指定城市的当前天气信息。

目前具体使用哪一个 API provider 尚未最终确定。

天气功能将通过 interface 与主要应用逻辑隔离，这样未来即使更换外部天气服务，也不需要对应用的核心逻辑进行大规模修改。

如果外部天气服务不可用，应用将使用默认场景。

---

## 第一版范围

Lo-Fi Companion 的第一版计划包含：

- 一个 Java Swing 主窗口，
- 一只虚拟宠物，
- 一个简单的 friendship 系统，
- 一个专注计时器，
- 专注 session 记录，
- 少量内置背景音乐，
- 基础播放和音量控制，
- 当前天气查询，
- 几种基于天气变化的房间场景，
- 以及本地 JSON 数据保存。

项目将优先保证应用规模较小但功能完整、可靠，而不是一开始加入大量复杂功能。

---

## 第一版暂不包含的功能

以下功能目前不计划加入第一版：

- 多人模式，
- 用户账户，
- 云同步，
- 多只宠物，
- 复杂剧情分支，
- 流媒体服务集成，
- 高级桌面悬浮功能，
- AI 生成对话。

只有在核心功能完成后，团队才会考虑是否加入这些扩展功能。
